Put image or PDF attachments for "Today's Insight" here (e.g.
`2026-07-08-chart.png`, `2026-07-08-report.pdf`), then reference the path
in `assets/data/insight.json`'s `media.url` field. See
`docs/MAKE-COM-SETUP.md` for the full walkthrough.

Video files for "Video of the Week" also go here (e.g.
`video-of-the-week.mp4`), referenced from `assets/data/video.json`'s
`filePath` field. See `docs/VIDEO-SETUP.md`.
